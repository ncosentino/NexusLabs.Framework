# NLF0010 — Place opening triple-quote on its own line, aligned with closing

**Severity:** Warning · **Category:** Usage · **Code-fix:** Yes

C# multi-line raw string literals (`"""..."""` or `$"""..."""`) strip
leading whitespace based on the column of the closing `"""`. When the
opening `"""` is left dangling at the end of an assignment or argument
line, the opening and closing tokens visually drift apart and the
literal's boundaries become hard to scan. Place the opening `"""` on its
own line at the same indent as the closing `"""`.

## Bad

```csharp
var sql = """
    SELECT *
    FROM users
    WHERE id = @id
    """;
```

```csharp
public const string Template = """
    {
        "name": "{{name}}"
    }
    """;
```

## Good

```csharp
var sql =
    """
    SELECT *
    FROM users
    WHERE id = @id
    """;
```

```csharp
public const string Template =
    """
    {
        "name": "{{name}}"
    }
    """;
```

The opening and closing `"""` now share the same column, and the content
indent visibly aligns with both. This is also the canonical shape the
content-stripping logic was designed for.

## Single-line raw strings are exempt

```csharp
var label = """value with "quotes" inside""";  // OK — no closing on a separate line
```

## Code fix

The shipped code fix automatically moves the opening `"""` to its own
line and re-indents to match the closing `"""`. Apply via the IDE's
"Fix all" action.

## When suppression is legitimate

Almost never. The rule is purely about layout, and the code fix is
mechanical.
