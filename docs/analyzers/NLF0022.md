# NLF0022 — Moq mocks must use MockBehavior.Strict

**Severity:** Warning · **Category:** Usage · **Code-fix:** No

Moq mocks must use `MockBehavior.Strict`. The rule fires on:

- a `Moq.MockRepository` constructed with a non-Strict behavior
  (`MockBehavior.Loose` or `MockBehavior.Default`), and
- a `repository.Create<T>(MockBehavior.Loose/Default, ...)` override that
  downgrades the behavior.

Direct `new Mock<T>(...)` is owned by NLF0021 (which forbids it outright), so
NLF0022 does not also flag it.

`MockBehavior.Loose` (Moq's default) returns a benign default for any
unconfigured member, which lets a test pass even when the code under test calls
something the test never anticipated. `MockBehavior.Strict` turns every
unconfigured call into an immediate failure, so a passing test means the
interaction matched exactly what was set up.

## Bad — non-strict behavior

```csharp
// ❌ NLF0022 — Loose lets unconfigured calls return silent defaults.
private readonly MockRepository _mocks = new(MockBehavior.Loose);

// ❌ NLF0022 — Default is Loose.
private readonly MockRepository _other = new(MockBehavior.Default);

public void M()
{
    // ❌ NLF0022 — per-mock override downgrades to Loose.
    var mock = _mocks.Create<IFoo>(MockBehavior.Loose);
}
```

## Good — strict behavior

```csharp
private readonly MockRepository _mocks = new(MockBehavior.Strict);

public void M()
{
    // Inherits the repository's strict behavior.
    var mock = _mocks.Create<IFoo>();
}
```

## When the analyzer stays silent

- The `MockRepository` is constructed with `MockBehavior.Strict`.
- `Create<T>()` is called with no behavior argument (it inherits the
  repository's strict behavior).
- The behavior argument is not a `Moq.MockBehavior` enum member the analyzer can
  resolve to a non-Strict value (e.g. a runtime variable).

## When suppression is the correct choice

For a deliberate loose mock — rare, and usually a smell — suppress with a
reason:

```csharp
#pragma warning disable NLF0022
var loose = _mocks.Create<IFoo>(MockBehavior.Loose);
#pragma warning restore NLF0022
```

Opt the whole project out via `dotnet_diagnostic.NLF0022.severity = none`.

## Related rules

- **NLF0021** — mocks must be created from a `MockRepository`, not
  `new Mock<T>()` / `Mock.Of<T>()`.
