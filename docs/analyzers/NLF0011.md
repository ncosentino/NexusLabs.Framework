# NLF0011 — Dispose TriedEx/TriedNullEx/Tried that wraps a disposable value

**Severity:** Warning · **Category:** Usage · **Code-fix:** No

`TriedEx<T>`, `TriedNullEx<T>`, and `Tried<T>` all implement `IDisposable`
and `IAsyncDisposable` so the wrapped value can be disposed automatically
via `using` / `await using` — without first having to check `Success`.

When you store one of these wrappers in a local whose `T` is itself
disposable, and you neither `using`-declare the local, return it, pass it
to another method, assign it to a field/property, nor call
`Dispose()`/`await DisposeAsync()` on it, the wrapped value silently
leaks. This analyzer reports that case so the leak surfaces at build time.

## Bad

```csharp
public async Task LoadAsync(CancellationToken ct)
{
    // MemoryStream is IDisposable; result goes out of scope undisposed → leak.
    var result = await TryOpenStreamAsync(ct).ConfigureAwait(false);
    if (result.Success)
    {
        Process(result.Value);
    }
}
```

## Good — using declaration

```csharp
public async Task LoadAsync(CancellationToken ct)
{
    using var result = await TryOpenStreamAsync(ct).ConfigureAwait(false);
    if (result.Success)
    {
        Process(result.Value);
    }
}
```

## Good — await using for IAsyncDisposable

```csharp
public async Task LoadAsync(CancellationToken ct)
{
    await using var result = await TryOpenStreamAsync(ct).ConfigureAwait(false);
    if (result.Success)
    {
        await ProcessAsync(result.Value, ct).ConfigureAwait(false);
    }
}
```

## Good — ownership transferred to caller

```csharp
public TriedEx<MemoryStream> Open()
{
    var result = TryOpenStream();
    return result; // caller now owns disposal
}
```

## Good — explicit disposal

```csharp
public void Load()
{
    var result = TryOpenStream();
    try
    {
        if (result.Success)
        {
            Process(result.Value);
        }
    }
    finally
    {
        result.Dispose();
    }
}
```

## When to suppress

The analyzer treats any of the following as ownership transfer / disposal:

- `using` (or `await using`) declaration on the local
- `return local;`
- `Method(local)` — passed as argument
- `this._field = local;` — assigned to field or property
- `local.Dispose();` or `await local.DisposeAsync();`

If your usage genuinely transfers ownership in a way the analyzer doesn't
detect (e.g. you store it in a dictionary via an indexer assignment that
the analyzer cannot reason about), suppress with `.editorconfig`:

```
[**/MyFile.cs]
dotnet_diagnostic.NLF0011.severity = none
```
