# NLF0023 — Match value types and records with an exact value or It.Is&lt;T&gt;

**Severity:** Warning · **Category:** Usage · **Code-fix:** No

`It.IsAny<T>()` is appropriate for reference types whose identity rarely matters
to an assertion, but for **value types** (`int`, `bool`, enums, `Guid`,
`DateTime`, `TimeSpan`, and other structs) and for **records** the exact value
is usually the thing a test should be pinning down. Matching `It.IsAny<int>()`
when the meaningful assertion is "called with 42" lets a regression that passes
the wrong number slip through.

`System.Threading.CancellationToken` is the only exempt value type:
`It.IsAny<CancellationToken>()` is the idiomatic way to express "any token" on a
mocked async member, where the specific token is genuinely irrelevant.

The analyzer fires only when the `It.IsAny<T>` type argument is a
non-`CancellationToken` value type or a record (including `record class`). Open
generic type parameters and reference types do not trigger it.

## Bad — It.IsAny on value types / records

```csharp
// ❌ NLF0023 — value type; assert the actual amount.
gateway.Setup(g => g.Charge(It.IsAny<decimal>()));

// ❌ NLF0023 — enum is a value type.
logger.Verify(l => l.Log(It.IsAny<LogLevel>(), ...));

// ❌ NLF0023 — record.
handler.Verify(h => h.Handle(It.IsAny<OrderPlaced>()));
```

## Good — exact value or It.Is&lt;T&gt;

```csharp
// Match the exact value (Moq matches values structurally).
gateway.Setup(g => g.Charge(19.99m));

// Match the relevant state with a predicate.
handler.Verify(h => h.Handle(It.Is<OrderPlaced>(o => o.OrderId == expectedId)));

// CancellationToken is exempt.
inner.Setup(c => c.OpenAsync(It.IsAny<CancellationToken>()));
```

## When the analyzer stays silent

- `T` is a reference type (`string`, interfaces, classes, delegates,
  `It.IsAnyType`).
- `T` is `System.Threading.CancellationToken`.
- `T` is an open generic type parameter (the kind is unknown at the call site).

## When suppression is the correct choice

Some value types genuinely carry no asserted value at a given site — most
commonly the `ILogger.Log` verification idiom, where `LogLevel` may be
unconstrained in a `Times.Never` "nothing was logged" check, or `EventId` is
not set by the code under test. Suppress with a reason:

```csharp
#pragma warning disable NLF0023 // EventId is not set by the SUT; level + message are the assertion.
logger.Setup(l => l.Log(level, It.IsAny<EventId>(), ...));
#pragma warning restore NLF0023
```

Opt the whole project out via `dotnet_diagnostic.NLF0023.severity = none`.
