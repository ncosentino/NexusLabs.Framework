# NLF0021 — Create Moq mocks from a MockRepository

**Severity:** Warning · **Category:** Usage · **Code-fix:** No

Moq mocks must be created from a shared `MockRepository`, not directly via
`new Mock<T>(...)` or `Mock.Of<T>(...)`.

A shared repository gives every mock one consistent behavior (created with
`MockBehavior.Strict` — see NLF0022) and lets a single `_mocks.VerifyAll()`
assert that every configured setup was exercised. A mock created outside any
repository has whatever the per-call default behavior is and participates in
no centralized verification.

## Bad — direct mock creation

```csharp
public sealed class OrderServiceTests
{
    public void Charges_the_card()
    {
        // ❌ NLF0021 — direct construction, no repository.
        var gateway = new Mock<IPaymentGateway>();

        // ❌ NLF0021 — Mock.Of shorthand is also forbidden.
        var clock = Mock.Of<IClock>();

        // ❌ NLF0021 — target-typed new is the same thing.
        Mock<ILedger> ledger = new();
    }
}
```

## Good — mocks from a shared repository

```csharp
public sealed class OrderServiceTests
{
    private readonly MockRepository _mocks = new(MockBehavior.Strict);

    public void Charges_the_card()
    {
        var gateway = _mocks.Create<IPaymentGateway>();
        var clock = _mocks.Create<IClock>();

        var sut = new OrderService(gateway.Object, clock.Object);
        // ... arrange setups, act ...

        _mocks.VerifyAll();
    }
}
```

## When the analyzer stays silent

- The created type is not `Moq.Mock<T>` and the invoked factory is not
  `Moq.Mock.Of` (matched by namespace + name; same-named types in other
  namespaces are unaffected).
- The mock is obtained via `repository.Create<T>()` — the required pattern.

## When suppression is the correct choice

If a specific test legitimately needs a standalone mock outside any repository,
suppress at the call site with a reason:

```csharp
#pragma warning disable NLF0021
var throwaway = new Mock<IFoo>();
#pragma warning restore NLF0021
```

Opt the whole project out via `dotnet_diagnostic.NLF0021.severity = none`.

## Related rules

- **NLF0022** — the `MockRepository` (and any per-mock override) must use
  `MockBehavior.Strict`.
- **NLF0023** — value-type / record arguments should be matched exactly rather
  than with `It.IsAny<T>()`.
