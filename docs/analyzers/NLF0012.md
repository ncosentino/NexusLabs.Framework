# NLF0012 — Parameterless [TransfersOwnership] on non-disposable member is inert

**Severity:** Warning · **Category:** Usage · **Code-fix:** No

`[NexusLabs.Framework.TransfersOwnership]` (with no targets) only takes
effect when it is placed on a member whose type implements `IDisposable` or
`IAsyncDisposable` — that is "Shape B", the direct ownership claim used by
`TransfersOwnershipDisposeSuppressor` (NLFSUP001) to silence IDISP007 on
that member's disposal.

When the parameterless form is placed on a non-disposable member (a `bool`
flag, an `int`, an enum, etc.), the suppressor never matches it. The
developer who wrote the annotation expecting suppression sees IDISP007 still
firing and is left with a silent no-op.

NLF0012 surfaces that footgun at build time. To resolve it:

- **Shape A (conditional ownership):** add the simple names of the
  disposable members this flag authorises, using `nameof(...)` so the link
  is rename-safe.
- **Shape B (direct ownership):** move the attribute onto the disposable
  member itself.

## Bad — parameterless on a flag

```csharp
public class StreamWrapper : IDisposable
{
    private readonly Stream _inner;

    [TransfersOwnership] // NLF0012: inert; _takeOwnership is not disposable
    private readonly bool _takeOwnership;

    public void Dispose()
    {
        if (_takeOwnership)
        {
            _inner.Dispose(); // IDISP007 still fires
        }
    }
}
```

## Good — Shape A with explicit targets

```csharp
public class StreamWrapper : IDisposable
{
    private readonly Stream _inner;

    [TransfersOwnership(nameof(_inner))]
    private readonly bool _takeOwnership;

    public void Dispose()
    {
        if (_takeOwnership)
        {
            _inner.Dispose(); // IDISP007 suppressed
        }
    }
}
```

## Good — Shape B on the disposable

```csharp
public class StreamWrapper : IDisposable
{
    [TransfersOwnership]
    private readonly Stream _inner;

    public void Dispose() => _inner.Dispose(); // IDISP007 suppressed
}
```

## Bad — parameterless on a constructor parameter that gates ownership

```csharp
public class StreamWrapper(Stream inner, [TransfersOwnership] bool takeOwnership)
    : IDisposable // NLF0012 on the parameter attribute
{
    public void Dispose()
    {
        if (takeOwnership)
        {
            inner.Dispose();
        }
    }
}
```

## Good — Shape A on the parameter

```csharp
public class StreamWrapper(
    Stream inner,
    [TransfersOwnership(nameof(inner))] bool takeOwnership) : IDisposable
{
    public void Dispose()
    {
        if (takeOwnership)
        {
            inner.Dispose();
        }
    }
}
```

## When NOT to fire (rule does not flag these)

- Parameterless on a disposable: `[TransfersOwnership] private readonly Stream _x;`
- Parameterless on `IDisposable` / `IAsyncDisposable` interface-typed members
- Any `[TransfersOwnership(...)]` with at least one target name, regardless
  of the annotated member's type — Shape A intent on a non-disposable is
  the documented use
- Generic members where the type parameter is constrained to
  `IDisposable`: `class Foo<T> where T : IDisposable { [TransfersOwnership] T _x; }`

## When to suppress

There is no legitimate reason to suppress NLF0012 — a parameterless
annotation on a non-disposable cannot suppress anything. If the analyzer
fires, the annotation is genuinely doing nothing and should be either
extended with targets or moved onto the disposable member.

## Related rules

- **NLFSUP001** — Suppresses IDISP007 in the two shapes described above.
- **IDISP007** (IDisposableAnalyzers) — The diagnostic that
  `[TransfersOwnership]` exists to selectively silence.
